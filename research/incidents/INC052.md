# INC052 — Minot AFB, ND: LFs O-6, N-7, Oscar/November LCFs, Bowbells area; B-52 inbound (5th BW)

- **Date:** 1968-10-24
- **Significance:** CRITICAL · **Status:** PARTIALLY_VERIFIED (confidence 3/5) · **Basis:** DOCUMENT_AND_WITNESS

## Description (as presented in the book; paraphrase)
Camper/maintenance teams and Base Ops log report bright maneuvering object near N-7; weather radar tracks object near Bowbells; B-52 radar paced by return 'as big or bigger than a KC-135' for ~20 mi, UHF transmitters disrupted; radarscope camera 14 frames; B-52 directed over ground-hovering oval orange object with tube and crescent; Blue Book case 12,548.
